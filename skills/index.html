Sprint Loops

Loop engineering protocol

The problem: long-horizon autonomous coding drifts — agents lose the plot across sessions, redo work, and leave no audit trail.
The skill: a lightweight five-phase protocol (Research → Plan → Build → Test → Loop) with persistent state on disk. The filesystem is the state machine. Ships three ways: a Claude Code plugin marketplace, a Codex CLI skill, and a runtime-agnostic spec for open harnesses.

GECK

Structured memory framework

The problem: context amnesia. Every CLI-agent session starts from zero — repeated mistakes, forgotten decisions, no coherence across a large project.
The skill: the Garden of Eden Creation Kit — a protocol plus generator that gives agents typed tasks, decision records, learnings, and episodic logs in a structured folder, read within a declared context budget.

MDR

Download resilience skill

The problem: multi-hour, multi-gigabyte model downloads from HuggingFace die at 87% and nobody notices until morning.
The skill: Massive Download Resilience — procurement of large models with nested cron jobs that watch, resume, and verify until the weights are truly on disk. Works from Claude Code, Codex, and Antigravity.

Supporting cast: oovra (compose and diff agentic system prompts from standardized .md + TOML elements) and .lux (a document format designed for human and AI readers as first-class consumers).
